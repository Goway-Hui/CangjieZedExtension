# Cangjie File Icons

Material Design 风格文件图标主题，适用于 Zed 编辑器。在 [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme) 基础上增加了仓颉语言（`.cj`）专属图标。

## 原项目

本图标主题基于 [vscode-material-icon-theme](https://github.com/material-extensions/vscode-material-icon-theme)（v5.35.0），由 [Material Extensions](https://github.com/material-extensions) 开发和维护。

## 新增内容

在原 Material Icon Theme 的基础上，本扩展新增了：

- **仓颉文件图标** — `.cj` 文件专属的仓颉语言图标
- **Zed 图标主题格式** — 将 VS Code 的 `fileExtensions` / `fileNames` / `folderNames` 映射转换为 Zed 的 `file_suffixes` / `file_stems` / `folder_icons` 格式

## 图标统计

| 类型 | 数量 |
|------|------|
| 文件后缀映射 | 1,359 |
| 文件名映射 | 105 |
| 文件夹映射 | 927 |
| SVG 图标 | 892 |

## 使用

在 Zed 的 `settings.json` 中设置：

```json
"icon_theme": {
    "dark": "Cangjie File Icons"
}
```
